# Computer Equipment Store System – Frontend

Frontend част на уеб базирана система за онлайн магазин за компютърна техника и услуги.

---

## 🛠 Използвани технологии

* Java
* Spring Boot
* Thymeleaf
* Bootstrap
* HTML / CSS
* JavaScript

---

## 🚀 Стартиране

### 1. Стартирайте backend приложението

```
http://localhost:8080
```

### 2. Стартирайте frontend проекта

```bash
./mvnw spring-boot:run
```

Приложението ще бъде достъпно на:

```
http://localhost:8081
```

---

## 🔗 Връзка с backend

Frontend приложението комуникира с backend чрез HTTP заявки към:

```
http://localhost:8080
```

---

## 📌 Основни функционалности

* Разглеждане на продукти
* Филтриране и търсене
* Детайли за продукт
* Количка
* Поръчка
* Потребителски профил
* Административен панел
